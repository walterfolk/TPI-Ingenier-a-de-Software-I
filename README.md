# Prototipo Spec 1 — Realizar Recorrido
Sistemas Triciclos UNTDF / Ingeniería de Software I.

## Ejecución

- `npm install`: instalar dependencias.
- `npm run dev`: iniciar el servidor de desarrollo.
- `npm test`: ejecutar tests unitarios y de componentes con Vitest.
- `npm run build`: compilar el proyecto.
